# RUMBA RU — пилот RAGU, Meno-Lite-0.2

Завершены 50 из 50 вопросов фиксированного пилота: 3 пользователя, 155 сессий, 411 фрагментов. Это отладочный пилот с балансом четырёх категорий, а не оценка всего test (1543 вопроса).

Протокол: greedy (`temperature=0`, `top_p=1`, `top_k=-1`, `min_p=0`), seed 42, `repetition_penalty=1.03`. TwoStageArtifactsExtractorLLM с NEREL, ICL=1, проверкой сущностей и связей; BM25 + BGE-M3; local search, reranker BGE-reranker-v2-m3, top-20 → top-5 сущностей. Контекст поиска — 12000 токенов по tiktoken gpt-4o; ответ — максимум 256 токенов.

Короткие запросы направлялись в native 32768, длинные — в отдельный YaRN ×2 endpoint 65536; маршрут определялся по точному числу chat-токенов плюс резерву ответа. Все 50 ответов получены через native. Эмбеддер и реранкер прошли preflight с контекстом 8192; размерность эмбеддингов — 1024.

F1 усреднён по вопросам, реализация LightEval 0.13.0 без нормализации. Официальный `rumba_metric` ожидает Pollux: оценено 0/50 ответов. Судейский этап использует сохранённые предсказания; для сравнения трёх моделей планируется оценить их ответы на тех же 50 вопросах.

Проверки: 50 уникальных ID совпадают с фиксированным пилотом; пустых ответов и ответов с finish_reason=length — 0; ошибок LLM при извлечении — 0; все графы согласованы и все 411 исходных фрагментов сохранены.

Поиск нашёл все evidence-сессии для 37/50 вопросов; средний recall evidence-сессий — 0.8267. Для 34/50 вопросов в итоговом промпте есть хотя бы один полный фрагмент каждой evidence-сессии; соответствующий средний recall — 0.7767. Это диагностика на уровне сессий: она не проверяет наличие конкретного факта внутри выбранного фрагмента. RAGU может усекать найденные фрагменты при упаковке в лимит контекста.

При индексации NEREL принял 1671 из 6218 кандидатов связей до объединения и дедупликации; отфильтровано 73.1%. Доля относится к кандидатам связей; корректность каждого факта требует отдельной проверки. Основные причины фильтрации — несовместимые типы концов связи, отсутствующий конец связи, самоссылки и неизвестные типы.
