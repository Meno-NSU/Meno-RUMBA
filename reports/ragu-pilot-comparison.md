# RUMBA RU — сравнение пилотов RAGU

Одинаковые 50 вопросов, 3 пользователя, 155 сессий и 411 фрагментов. Greedy, seed 42, repetition_penalty 1.03; общий протокол индексации и поиска. F1 — среднее по вопросам, без нормализации. Это отладочный пилот, а не оценка всего test (1543 вопроса).

Официальный rumba_metric ожидает Pollux: оценено 0/50 для каждого завершённого пилота. Следующий этап — пилот Meno-Lite-0.1, затем оценка сохранённых 150 ответов судьёй; перед массовой оценкой — smoke формата и парсинга на 5–10 ответах.

Во всех завершённых пилотах: 50/50 ответов, ошибок извлечения и обрезаний — 0, графы согласованы, все источники сохранены. Короткие запросы Meno шли без YaRN, длинные — с YaRN ×2; у Qwen оба окна native. Все 100 итоговых ответов получены через короткие endpoint. Код и generation-протокол совпадают по хэшам; точные ревизии локальных весов не подтверждены.

Проекция полного прогона на текущем развёртывании: Meno-Lite-0.2 — около 18 часов (по двум историям без ранее готовых генераций); Qwen3.5-9B — около 17 часов (по трём пилотным историям). При сопоставимой скорости Meno-Lite-0.1 разумный предварительный бюджет на три последовательных полных прогона — 2–3 суток до судейского этапа. Это линейная оценка по 10766 фрагментам, а не результат полного измерения; время Pollux ещё не измерено.
