# RUMBA RU — пилот RAGU, Meno-Lite-0.1

Завершены 50 из 50 вопросов того же фиксированного пилота: 3 пользователя, 155 сессий, 411 исходных фрагментов. Это отладочный пилот, а не оценка всего test (1543 вопроса).

Протокол совпадает с двумя предыдущими пилотами по хэшам кода и параметрам: greedy, seed 42, repetition_penalty 1.03; TwoStageArtifactsExtractorLLM с NEREL, ICL=1, проверкой сущностей и связей; BM25 + BGE-M3; local search с BGE reranker, top-20 → top-5 сущностей. Контекст поиска — 12000 токенов по tiktoken gpt-4o, ответ — максимум 256 токенов. Каждая модель независимо строила графы и отвечала по своему результату поиска: это end-to-end сравнение.

Для Meno-Lite-0.1 использованы native 32768 без YaRN и длинный endpoint 65536 с YaRN ×2. Роутер учитывает точные chat-токены плюс резерв генерации. Длинный endpoint проверен на 45043 входных токенах, число /tokenize совпало с usage. Индексация: 1529 вызовов native и 126 через YaRN; все 50 ответов — native. Эмбеддер и реранкер прошли preflight с контекстом 8192, векторы — размерности 1024.

F1 усреднён по вопросам (LightEval 0.13.0 без нормализации); официальный rumba_metric ожидает Pollux (0/50 оценено).

QC: ID совпадают с фиксированным пилотом; дубликатов, пустых и обрезанных ответов — 0; ошибок API/JSON при извлечении — 0; графы согласованы; все 411 фрагментов сохранены.

Все evidence-сессии найдены для 25/50 вопросов; средний recall — 0.6367. Для 25/50 вопросов в итоговом промпте есть хотя бы один полный фрагмент каждой evidence-сессии, средний recall по этому признаку — 0.6367. Это диагностика на уровне сессий, а не точных spans фактов.

NEREL принял 373 из 2003 кандидатов связей до объединения и дедупликации; отфильтровано 81.4%. Основные причины — неизвестные типы и отсутствующие концы связей. Доля относится к кандидатам и сама по себе не измеряет долю сохранённых верных фактов.
